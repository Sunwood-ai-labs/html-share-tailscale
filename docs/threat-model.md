# セキュリティ設計

## 前提

- 共有対象は、利用者が自分のPC上で生成・登録したHTMLです。
- Tailscale ACLとTailnet参加者がアクセス主体です。
- Tailscale Funnelや公開ホスティングは使いません。
- ローカルサーバーは `127.0.0.1` だけで待ち受けます。

## 保護しているもの

- 未公開のHTMLレポート
- レビュー依頼と回答
- 既読・スターなどの表示設定
- 期限付き共有リンクのトークン

## 境界

TailscaleのACLが最初の境界です。さらに、生成HTMLを置くサイトディレクトリと、レビュー・設定を置くデータディレクトリを分離しています。設定ファイル、秘密鍵、環境変数を静的サイトから配信しません。

## HTMLの扱い

HTMLは信頼できるソースから登録してください。HTML内のJavaScriptはブラウザ上で実行されるため、悪意のあるHTMLを登録すると、Tailnet内の閲覧者に影響します。CLIは許可したroots外のページやローカルアセットを拒否し、外部アセットは埋め込みません。

## 期限付きリンクの限界

期限付きリンクはサーバー側で期限を検査しますが、閲覧者が内容を保存した後の回収はできません。元ページの直接URLは、ページが公開されている間、Tailnet内で利用できます。

## 想定しない脅威

- 侵害済みのTailnet端末
- Tailscale ACL管理権限の侵害
- 登録したHTML自体が悪意を持つケース
- 利用者が意図的にTailscale Funnelや別の公開プロキシを追加するケース

これらはHTML共有くん単体では防げないため、Tailnet ACL、端末の更新、HTMLソースのレビューで管理してください。
