# セキュリティ設計

[ドキュメント入口](../index.md) · [English](../../guide/threat-model.md)

このプロジェクトはプライベートなTailnet向けであり、公開ホスティングサービスとして設計していません。

## 保護する対象

- 未公開のHTMLレポート
- レビュー依頼と回答
- 既読、スター、ダッシュボード設定
- 期限付き共有リンクのトークン
- ローカル設定と共有root

## 想定する境界

- どのTailnet identityが到達できるかはTailscale ACLで決まる
- HTTPサーバーは既定でループバックにバインドする
- 明示的な入口はTailscale Serve
- `.env`、ローカルYAML設定、`.html-share/` はGitで無視する

## 信頼する前提

- TailnetとACL管理者を信頼する
- ホストPCと接続端末を適切に更新・管理する
- 登録したHTMLが閲覧者のブラウザで実行されることを理解する
- 実在ホスト名、IP、トークン、業務データを追跡対象のサンプルへ入れない

## 重要な制約

- 侵害済みのTailnet端末からは守れない
- 閲覧者が保存した内容を期限付きリンクから回収することはできない
- 登録HTMLはJavaScriptを実行できるため、共有前に確認が必要
- オペレーターが別の公開プロキシやTailscale Funnelを追加することは止めない
- アプリケーション認証、監査ログ、企業向けDLPの代替ではない

## 安全な運用ルール

originはループバックに置き、Tailscale ACLを意図どおりに設定し、マシン固有値は `.env` へ置き、信頼できるHTMLだけを登録してください。Tailnet外へ公開したい場合は、この境界を無理に変えず、公開配信用に設計された別の製品を選んでください。
