# HTML Share documentation

[日本語ドキュメント](/ja/) · [English README](https://github.com/Sunwood-ai-labs/html-share-tailscale#readme)

HTML Share is a local-first HTML dashboard that is reachable through Tailscale Serve. The app stores its site and review state on the host PC; the public-facing network boundary is the Tailnet.

## Guides

- [Setup](guide/setup.md) — install, configure `.env`, publish, and expose the loopback server through Tailscale Serve.
- [Usage](guide/usage.md) — register reports, create expiring links, and move review requests between devices.
- [Architecture](guide/architecture.md) — understand the local site, data store, API, and Tailnet route.
- [Threat model](guide/threat-model.md) — know what the Tailnet boundary protects and what it does not.
- [Troubleshooting](guide/troubleshooting.md) — resolve configuration, port, and missing-page problems.
