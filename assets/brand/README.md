# Brand direction

`html-share-tailscale-header.png` is the imagegen-produced repository header for this fork. The companion SVGs provide the compact fallback mark and a code-native visual system:

- **Tail sweep** — HTML travels from local storage through the Tailnet to a phone or another PC.
- **Geometric torii** — a clear Japanese gateway for the Tailscale access boundary.
- **Cyan nodes** — asynchronous review and handoff between a coding agent and a mobile screen.
- **Vermilion / gold / indigo** — a restrained Japanese rock palette that stays legible in a GitHub README.

The artwork is intentionally abstract. It does not copy the Tailscale logo or any other third-party mark. Keep the SVGs flat, geometric, and readable at both banner and icon sizes; keep the generated PNG wide, legible, and suitable for the README header.
